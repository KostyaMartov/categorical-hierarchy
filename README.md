# 🧠 Когнитивный анализатор на основе теории категорий

> **«Моделируем мышление как иерархию абстракций, динамику через эндофункторы и неопределённость через монады»**

Это первый в мире **open-source инструмент**, который применяет **полную структуру теории категорий** для анализа поведенческих данных:

- 🧱 **Иерархия абстракций** — автоматическое обобщение через кластеризацию,
- 🔄 **Естественные преобразования** — сравнение когнитивных моделей,
- ⏳ **Эндофункторы** — моделирование временной эволюции поведения,
- 🎲 **Монады и категория процессов** — вероятностные поведенческие сценарии,
- 🤖 **Семантические имена** — генерация через Qwen (локально, без облака),
- 🎨 **Интерактивная визуализация** — в браузере, без установки.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/ваш-логин/categorical-hierarchy)

## 🌟 Возможности

| Функция | Описание |
|--------|---------|
| **Анализ циклов** | Обнаружение порочных кругов: `стресс → покупки → вина → стресс` |
| **Иерархия уровней** | Уровень 0: конкретные действия → Уровень 2: глубинные мотивы |
| **Сравнение моделей** | Как изменилось поведение до/после терапии? |
| **Вероятностные процессы** | Оценка риска входа в негативный цикл (например, 43%) |
| **Генерация имён** | `shopping` → **«компенсаторные покупки»** (через Qwen) |
| **Локальная работа** | Все данные остаются на вашем компьютере — никакого облака! |
